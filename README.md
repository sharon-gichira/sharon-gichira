## About Me

I'm a Data Analyst with a quantitative background in Finance and Statistics, combining formal training in statistical methods with hands-on experience in audience analytics, campaign performance measurement, and market research. At Royal Media Services, I worked at the intersection of data and marketing strategy, analyzing large-scale audience datasets to uncover engagement trends, building KPI dashboards used by cross-functional teams, and designing surveys that informed senior leadership's content decisions.

My technical foundation spans SQL, Python, and data visualization tools, which I use to turn raw, often messy data into insights that are actually actionable for non-technical stakeholders. I'm comfortable running the full analytical process end to end: pulling and cleaning data from multiple sources, applying statistical methods like regression and hypothesis testing to validate patterns, and presenting findings in a way that supports real decisions rather than just describing the data.

Outside of my core marketing analytics work, I build independent data science and machine learning projects to deepen my applied skills — including a multi-model commodity price forecasting system for the Kenyan agricultural market and a predictive model for traffic crash outcomes. These projects reflect the same approach I bring to professional work: rigorous exploratory analysis, careful model evaluation, and a focus on producing outputs that are usable by people who aren't data specialists.

I recently completed a Data Science Bootcamp at Moringa School to formalize my machine learning skill set alongside my Finance and Statistics degree from Mount Kenya University, and I'm currently looking for Data Analyst and Data Scientist roles where I can apply both my analytical rigor and my experience communicating data insights to stakeholders.

### **Agricultural Commodity Price Forecast**
Co-developed an end-to-end machine learning forecasting system predicting retail and wholesale prices across 19 commodities, 100+ markets, and 30 counties in Kenya, addressing price information asymmetry for farmers and traders.

**Tech Stack**
- Python (Pandas, NumPy)
- SARIMA, LSTM, XGBoost
- React (deployed dashboard)
- Vercel

**Key Actions & Impact**
- Built and benchmarked 3 forecasting models (SARIMA, LSTM, XGBoost), evaluating performance via RMSE, MAE, and MAPE to select the optimal model per commodity
- Deployed an interactive React dashboard enabling non-technical users — farmers and traders — to view historical price trends and forecasts
- Worked across a large, multi-dimensional dataset spanning 30 counties and 100+ markets

**Key Actions & Impact**
