## 🚀 Main Projects

### 🌽 Agricultural Commodity Price Forecasting
Forecasts prices for 19 commodities across 100+ Kenyan markets using nearly 55,000 records. Compares SARIMA, LSTM and XGBoost, with missing data handled through source-level retrieval instead of imputation.
`Python` `SARIMA` `LSTM` `XGBoost` `Time Series`

### 🛒 Kenya Retail Analytics Capstone
End-to-end analysis of a Kenyan retail dataset (stores across counties, KES pricing, M-Pesa payments) adapted from the Dunnhumby Complete Journey data. Covers sales drivers, promotion lift, RFM customer segmentation and weekly sales forecasting against a naive baseline, with a PostgreSQL layer for analysis queries.
`Python` `PostgreSQL` `RFM` `Forecasting`

### ✈️ Airline Passenger Satisfaction Prediction
Classification model predicting passenger satisfaction, tuned with Optuna and evaluated on ROC-AUC.
`Python` `XGBoost` `Optuna`

### 🏨 Tembo Hotel Bookings Analysis

`SQL` `PostgreSQL`

### 🚦 Chicago Road Traffic Crashes

`Python` `pandas` `EDA`

### ❤️ World Hypertension Analysis
