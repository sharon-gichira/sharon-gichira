## 📂 Featured Projects

### 🌾 [Agricultural Commodity Price Forecasting](https://github.com/sharon-gichira/Agricultural-Commodity-Price-Forecasting)
Predicting agricultural price trends in the Kenyan market using **SARIMA**, **LSTM**, and **XGBoost**. Focused on delivering actionable insights for food security and market stability — a domain where data-driven foresight directly affects livelihoods.

---

### 🚗 [Chicago Road Traffic Crashes Analysis](https://github.com/sharon-gichira/Chicago-Crashes)
An end-to-end machine learning project using classification models to identify the primary contributory causes of traffic accidents. Applied model interpretability techniques to extract concrete road-safety recommendations from a 54,950-record dataset.

---

### 🛒 [Jumia E-commerce Analysis](https://github.com/sharon-gichira/Jumia-Analysis)
Exploratory and statistical analysis of consumer behavior trends on Kenya's largest e-commerce platform. Uncovered feature relationships and purchasing patterns to support data-backed business decisions.

---

### 🏥 [World Hypertension Analysis](https://github.com/sharon-gichira/World-Hypertension-Analysis)
A global data study exploring health trends and demographic risk factors associated with hypertension, using classification models including k-NN, Decision Trees, and Logistic Regression with cross-validation and F1-score evaluation.
